# Portfolio — Karthick C

A clean, responsive personal portfolio built with **React**, **Vite**, and **Tailwind CSS**.

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Lucide React (icons)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
